# ⚡ YazFit — نسخه آمریکا (US Edition)

اپلیکیشن کامل **طراحی برنامه تمرینی و غذایی اختصاصی** — وب‌سایت + اپ موبایل (PWA) + پلن‌های پولی + یادآوری، بر اساس بهترین استانداردهای بین‌المللی و **سبک زندگی آمریکایی**.

---

## 🚀 اجرا

**روش ۱ (ساده‌تر):** فایل `run.bat` را دابل‌کلیک کنید → مرورگر روی `http://localhost:8123` باز می‌شود.

**روش ۲ (دستی):**
```bash
cd "yaz fit"
python -m http.server 8123        # یا: npx http-server -p 8123
```

**روش ۳:** فقط `index.html` را باز کنید (بدون سرویس‌ورکر کار می‌کند؛ برای نصب روی موبایل حتماً از سرور اجرا کنید).

> 💡 برای دیدن خروجی سریع، در صفحه خوش‌آمد دکمه **«Try demo profile»** را بزنید (پروفایل آزمایشی John، ۲۱۲ پوند، هدف چربی‌سوزی).

## 📱 نصب روی موبایل (اپلیکیشن)

1. موبایل و کامپیوتر را در یک شبکه قرار دهید، سرور را اجرا کنید و آدرس IP کامپیوتر را در موبایل باز کنید (مثلاً `http://192.168.x.x:8123`)، یا پروژه را روی هر هاست استاتیک (Netlify/Vercel/GitHub Pages) بگذارید.
2. در اندروید: منوی کروم → **Add to Home Screen / Install**
3. در iOS: سافاری → Share → **Add to Home Screen**
4. اپ به‌صورت تمام‌صفحه، با آیکون و آفلاین (Service Worker) اجرا می‌شود.

- **WHO 2020** — ۱۵۰-۳۰۰ دقیقه هوازی + ۲ روز قدرتی

## 🗂 ساختار

```
yaz fit/
├── index.html      ← اسکلت اپ
├── styles.css      ← دیزاین‌سیستم (موبایل‌فرست، دارک/لایت)
├── data.js         ← دیتابیس غذاها، تمرین‌ها، قالب وعده‌ها، پلن‌های قیمت‌گذاری
├── engine.js       ← محاسبات و ژنراتورها (BMR/TDEE/ماکرو/اسپلیت/وعده)
├── app-views.js    ← رندر ۵ صفحه (Today/Workouts/Nutrition/Progress/Profile)
├── app-core.js     ← state، آنبوردینگ، اکشن‌ها، یادآوری، پرداخت، PWA init
├── manifest.json / sw.js / icons/   ← PWA
├── run.bat         ← اجرای سریع روی ویندوز
└── README.md
```

دیتا فقط در `localStorage` دستگاه ذخیر می‌شود (بدون سرور). با **Export JSON** قابل تهیه نسخه پشتیبان است.

## 💰 ب评为 محصول واقعی (نقشه راه)

1. **بک‌اند:** Supabase یا Firebase (Auth + DB) — ساختار state فعلی مستقیماً قابل انتقال است.
2. **پرداخت واقعی:** Stripe Checkout (سایت) + RevenueCat (اپ استور).
3. **اپ استور:** React Native / Expo یا Capacitor — همین کد وب با حداقل تغییر پکیج می‌شود؛ نوتیفیکیشن با FCM/APNs.
4. **قوانین:** صفحه Terms/Privacy (GDPR/CCPA)، دیسکلیمر پزشکی امضاشده در آنبوردینگ، بازبینی App Store Review (کته Health & Fitness).
5. **هوش مصنوعی:** جایگزینی engine با LLM + قواعد دامنه، یا برج‌های پیشنهادی adaptive فعلی.

## ⚠️ سلب مسئولیت

YazFit توصیه عمومی تناسب‌اندام است و **جایگزین توصیه پزشکی نیست**. افراد با بیماری زمینه‌ای، بارداری یا مصدمان باید قبل از شروع با پزشک مشورت کنند.

## 📄 نسخه تک‌فایلی دمو (بدون هاست و سرور)

`deploy/YazFit-Demo.html` — کل سایت (لندینگ + اپ + عکس‌ها) در **یک فایل HTML**. کافی است فایل را برای مشتری بفرستید؛ با دابل‌کلیک در هر مرورگر باز می‌شود. داده‌ها در localStorage مرورگر همان دستگاه ذخیره می‌شوند و با Export JSON (بخش Profile) قابل انتقال‌اند. بازسازی پس از هر تغییر: `python tools/build-single-file.py`
